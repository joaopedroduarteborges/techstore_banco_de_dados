# Projeto de Banco de Dados

## Sobre o projeto

Projeto acadêmico desenvolvido durante o curso de Engenharia de Software, com o objetivo de aplicar conceitos fundamentais de banco de dados relacionais.

## Tecnologias utilizadas

- MySQL
- SQL
- MySQL Workbench

## Funcionalidades

- Criação e organização de tabelas
- Consultas SQL
- Utilização de JOINs
- Criação de Views
- Implementação de índices

## Estrutura do projeto

- `database/`: estrutura e dados do banco.
- `consultas/`: consultas SQL desenvolvidas.
- `views/`: visualizações criadas.
- `indices/`: índices utilizados.

## Objetivo acadêmico

Aplicar conceitos de modelagem e gerenciamento de bancos de dados, desenvolvendo conhecimentos em SQL e organização de dados.
